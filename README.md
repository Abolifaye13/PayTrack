\# PayTrack



A collection of two Java Spring Boot assessment projects organized in a single repository.



\## Projects



\### 1. PayTrack – Spring Security

\*\*Folder:\*\* `paytrack-spring-security`



A Spring Boot application demonstrating:

\- Spring Security authentication and authorization

\- Organisation-based data access

\- PostgreSQL database integration

\- Flyway database migrations

\- Docker support



\### 2. Customer CRUD – GSTIN

\*\*Folder:\*\* `customer-crud-gstin`



A Customer Management application featuring:

\- Customer CRUD operations

\- GSTIN validation

\- Billing and shipping addresses

\- Role-based authorization

\- Application testing



\## Technology Stack



\- Java

\- Spring Boot

\- Spring Security

\- Maven

\- PostgreSQL

\- H2 Database

\- Flyway

\- Docker
